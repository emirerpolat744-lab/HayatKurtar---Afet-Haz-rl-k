# HayatKurtar

HayatKurtar projesinin GitHub Pages için dosyalara ayrılmış kopyası. Görünüm ve JavaScript işlevleri, sağlanan orijinal HTML içeriğinden korunmuştur. `HayatKurtar_Orijinal.html` tek dosyalı orijinal sürümdür.

## GitHub Pages ile yayımlama
1. Bu klasördeki dosyaları bir GitHub deposunun kök dizinine yükle.
2. Depoda **Settings → Pages** bölümünü aç.
3. **Deploy from a branch** seç; `main` ve `/(root)` seçip kaydet.
4. GitHub Pages adresi hazır olduğunda aynı Pages bölümünde görünür.

`index.html`, `style.css` ve `script.js` aynı klasörde kalmalıdır. Konum algılama gibi bazı tarayıcı özellikleri HTTPS üzerinden çalışır. Bu proje resmî acil durum uyarı sistemi değildir; acil durumda Türkiye'de 112'yi ara.
